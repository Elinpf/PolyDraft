## ADDED Requirements

### Requirement: 生成页下拉单选式

前端生成页 SHALL 改为下拉单选式：按已配置的选项维度动态渲染下拉框，用户选择各维度后触发生成，不再要求自由填空输入变量。

#### Scenario: 按维度渲染下拉框
- **WHEN** 用户进入生成页
- **THEN** 页面按已配置的选项维度动态渲染对应数量的下拉框
- **AND** 每个下拉框列出该维度的所有选项

#### Scenario: 选择后生成
- **WHEN** 用户在各下拉框选好选项并触发生成
- **THEN** 所选维度的值与 prompt 片段作为变量注入 prompt 渲染
- **AND** 流水线按现有方式（SSE 进度 + 并行多风格候选 + 审查）执行

#### Scenario: 无可用维度
- **WHEN** 未配置任何选项维度
- **THEN** 生成页提示去选项维度页配置
- **AND** 不阻止其他已配置维度的展示
